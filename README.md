# Dotfiles - Arch Linux Config

![Preview](https://github.com/doanhaoCoder/dotfiles-assets/blob/master/preview.gif)

## 🛠 Introduction
This is my **dotfiles** setup for **Arch Linux**, optimized for **Hyprland**, **Neovim**, and various other tools to enhance the workflow experience.

## 🚀 Installation
```bash
git clone https://github.com/doanhaoCoder/dotfiles.git ~/dotfiles
cd ~/dotfiles
bash setup.sh
```
